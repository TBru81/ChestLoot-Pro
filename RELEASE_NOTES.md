# ChestLoot Pro 1.0 — release notes

This first three-mode public build is promoted from the player-tested 0.9.0 RC5 package. Its behavior is unchanged apart from version labels and the new, distinct launcher filename.

## Included and tested

- Dungeon Chest Mode, Shop Chest Mode, and Exodus Decorative Box Mode.
- Fresh-install Dungeon Magic Item minimum tier: Lesser Magic.
- The verified PetMedic-style action arrow art ID `5837` and consistent row placement.
- Shared branded title on Options and rare-list gumps, including transparent mode; a contextual Rare Dungeon Items or Rare Shop Items label sits within the content area.
- Two-column Exodus Options layout and aligned section spacing. Dungeon and Shop end with Trap Removal, recorded list, then Transparency.
- Shop rare-item recording and player-directed theft, tested in game.

Kotl Regal Case Mode is withheld until further field testing. This package includes no pre-existing JSON settings or learned-item records. Keep your own JSON files if you want to carry those records forward.

Offline verification: the 12 RC5 checks passed before the 1.0 package was prepared. These checks are not a substitute for Razor Enhanced and in-game testing of the packaged download.
